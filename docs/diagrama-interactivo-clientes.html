Cómo se implementó

Vista

React muestra Login, Registro de cliente, Mi perfil, Clientes y Administración → Talleres. Oculta las opciones no autorizadas, pero no decide la seguridad.

API, Facade y Repository

Express recibe HTTP; el Facade normaliza y valida reglas de negocio; el Repository ejecuta consultas parametrizadas contra MySQL.

Datos persistentes

Clientes, Talleres, relaciones, actividades y caché SEPOMEX viven en MySQL. Las fotos usan nombres UUID y no dependen del nombre recibido.
